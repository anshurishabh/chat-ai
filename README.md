# 🛠 Tech Stack

| Category | Technology |
|----------|------------|
| Frontend | Next.js 16 |
| Styling | Tailwind CSS |
| State | Zustand |
| Backend | Node.js + Express |
| Database | MongoDB |
| Real-time | Socket.IO |
| AI | Groq + HuggingFace |
| Video | Agora RTC |
| Storage | Cloudinary |
| Authentication | JWT |
| Notifications | Web Push |
| Deployment | Vercel + Render |

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/anshurishabh/chat-ai.git

cd chat-ai
```

Backend

```bash
cd server
npm install
npm run dev
```

Frontend

```bash
cd client
npm install
npm run dev
```
