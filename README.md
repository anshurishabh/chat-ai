# NexChat - AI Powered Chat Application

A full-stack real-time chat application with AI features.

## 🚀 Live Demo
- Frontend: https://chat-ai-18y1.vercel.app
- Backend: https://nexchat-server-w5gq.onrender.com

## ✨ Features
- 💬 Real-time messaging (Socket.IO)
- 👥 Group chats
- 🤖 AI Assistant (Groq/LLaMA)
- 🌍 Auto language translation
- ✨ AI grammar correction
- 📝 Chat summarizer
- 📎 File sharing (Images, Videos, PDFs)
- 🎤 Voice messages
- 📞 Voice & Video calls (WebRTC)
- 🔔 Push notifications
- 🟢 Online/Offline status
- ✍️ Typing indicators

## 🛠️ Tech Stack
- **Frontend:** Next.js, Tailwind CSS, Zustand
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Real-time:** Socket.IO
- **AI:** Groq API (LLaMA 3.1)
- **Storage:** Cloudinary
- **Auth:** JWT
- **Deployment:** Vercel + Render
